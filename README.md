# Multiside
A Melonloader mod to allow chaotic multiplayer gameplay in Miside Zero. Powered by Photon.

**NOT compatabile with Miside!**

## Installation

#### Install MelonLoader

 - Download and run MelonLoader Installer from [here](https://melonwiki.xyz/#/)

 - Select the game’s .exe file.

 - Install v0.7.2 or later or it will crash

After installation, your game directory will contain:  
``Mods``  
``Plugins``  
``UserData``  
``MelonLoader``  

#### Install the mod

Get the latest release. https://github.com/Gameknight963/Multiside/releases/latest

Follow the instructions there.

Upon launching, you will automatically connect to the server.
